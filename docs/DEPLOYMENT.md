# Deployment

## Target

GitHub → Vercel → `cannacoreseeds.com`

## Vercel settings

- Framework Preset: Next.js
- Root Directory: `./`
- Build Command: Default
- Output Directory: Default
- Install Command: Default

## Domain

Attach both `cannacoreseeds.com` and `www.cannacoreseeds.com` to the single production Vercel project intended to serve this repo.
